# Fla. Stat. § 55.207 — Correction of judgment lien file.

**Title:** VI — CIVIL PRACTICE AND PROCEDURE
**Chapter:** 55 — JUDGMENTS
**Part:** XII — DOMESTIC VIOLENCE
**Section:** 55.207
**Source:** 2025 Florida Statutes (FLLawDL2026)

---

(1)  
A person may file with the Department of State a correction statement with respect to a judgment lien file, as provided in s. 55.203, indexed under any person's name, if the person believes that the file is inaccurate or that the judgment lien certificate was wrongfully filed.

(2)  
A correction statement must:
(a)  
State the judgment debtor named and the file number assigned to the judgment lien file to which the correction statement relates;

(b)  
Indicate that it is a correction statement;

(c)  
Provide the basis for the person's belief that the judgment lien certificate was wrongfully filed or the file is inaccurate; and

(d)  
Indicate the manner in which the person believes the file should be corrected to cure any inaccuracy.

(3)  
The department shall ensure that a correction statement is indexed and available in the same manner as any filed lien certificate in the central database of judgment lien files.
